Automated Paper Checking System
Final Year Project

A web application that automatically evaluates handwritten exam papers. The system uses a hybrid OCR approach — EasyOCR for printed characters and TrOCR for cursive handwriting — with OpenCV preprocessing handling image skew, noise, and contrast before recognition. Results are stored in SQLite and reviewed through a Flask web interface.

ProblemManual paper grading is slow, inconsistent, and labour-intensive for educators
SolutionHybrid OCR pipeline + automated scoring logic inside a Flask web app
